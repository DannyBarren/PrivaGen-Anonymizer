Data Safety Guarantees

Non-destructive · Copy-only

Safe mode: the original dataset is only ever copied. Nothing is written back to the source.

  • ✓ Original dataset is never modified or deleted
  • ✓ All processing runs on copies only (secure temp_processed/ workspace)
  • ✓ Source directory input_raw/ is treated as read-only (set to 0444 on ingest)
  • ✓ A write guard blocks any accidental write back to the original location
  • ✓ Failed items are copied, not moved — nothing is ever lost from the source
  • ✓ Remote source is read with a read-only key; ingest uses rclone copy — never move, sync, or delete
